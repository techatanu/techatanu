# About Me :
B.Tech CSE undergraduate at Rishihood University (Sonipat, Haryana) focused on AI agents, machine learning and full-stack development. Skilled in Python, LangGraph, RAG, LLMs (Groq / Llama), scikit-learn, FastAPI, Streamlit, React and Node.js. Built projects in exam-question difficulty prediction with a RAG agent, infant cry classification from audio, an AI GitHub portfolio reviewer and a full-stack health record manager. Open to remote AI/ML and full-stack internships.
